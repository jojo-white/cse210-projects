The program is fairly simple to use, it allows you to put in any information you want about any celestial object type that is given in the program.

The program will tell you what units to use when measuring your celestial objects' distance, and it will ask you if you want to measure the angular size in degrees, arcminutes, or arcseconds.

The program will find an approximate size of your object, with the size being more accurate with more significant numbers you have in your distances and angle measurements.

When calculating if an object is a black hole, it will ask you for it's mass in kilograms. You WILL need to put a very, VERY large number into that field. The bigger the object, the more zeros you will need to add on to the end of your number for the mass.
